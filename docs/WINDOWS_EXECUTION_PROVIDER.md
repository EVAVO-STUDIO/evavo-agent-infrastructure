# Windows execution provider

Physical Windows execution belongs to `EVAVO-STUDIO/evavo-local-compute`.

This repository may expose transport, client registration and readiness information. Its legacy `windows-chat-execution` shim must not regain raw command authority or become a second executor. Effectful requests go to the Local Compute Workstation Bridge or Workstation Operator. Hosted-chat recovery uses the Local Compute GitHub Issues poller and does not require GitHub Actions or Vercel.

BeeStation paths, Windows credentials and physical execution claims are owned and proven locally by Local Compute and Local Storage receipts. They must not be hard-coded here.
